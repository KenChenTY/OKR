## 数据库与运行边界

迁移版本为 `0001` 至 `0006`。包含核心业务、治理、举措收益、可见范围、本地账号、复盘及战略评估迁移。离线 SQL 位于 `deploy/sql/002-alembic-upgrade.sql`，运行身份权限样例位于 `deploy/sql/runtime-role.sql`。迁移由独立发布身份执行，应用启动不会自动创建数据库。

数据库只支持 SQL Server。未配置数据库时可浏览登录页、检查存活状态及运行独立测试，不能登录并执行业务操作。页面不会用演示记录替代真实服务。

后台 Worker 需单独运行，负责通知、附件扫描、导出与快照。通知当前为站内通知，不发送邮件或即时通讯消息。扫描器需部署实际可用的命令行程序，退出码约定见部署文档。

## 当前约束与后续工作

- 每名用户当前使用一个主角色和一个组织；审批链固定为两级，不包含可视化流程设计、委托及自动组织同步。身份及组织初始化由管理命令完成。
- 外部项目、Power BI、SharePoint 等目前提供受控链接；自动同步连接器、Webhook、凭据托管及异常补偿仍需后续开发与外部系统联调。
- AI 起草、检查与总结尚未实现。
- 文件支持 XLSX、PPTX、PDF、PNG、JPEG；旧版 XLS/PPT 未开放。历史证据不覆盖，保留不可变版本。
- 健康度阈值和业务时区目前为全局配置，不是逐组织规则。收益重复登记依赖唯一业务编号，不能自动识别不同编号背后的同一项收益。
- 导出每次最多 2,000 个目标、每用户最多三个待处理任务，下载有效期为 24 小时；过期文件的磁盘清理由运维制定保留策略。
- 生产容量、Windows 下 Nginx 性能、证书、Entra 条件访问/MFA、病毒扫描、备份恢复及真实数据库并发与故障恢复尚未验收。
